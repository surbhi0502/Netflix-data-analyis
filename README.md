# Netflix Data Analysis

## 📌 Project Overview

This project analyzes Netflix movies and TV shows using Python, MySQL, and Power BI.

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- MySQL
- SQL
- Power BI
- Jupyter Notebook

## 📊 Project Objectives

- Analyze Netflix content by year
- Analyze movies and TV shows
- Identify popular genres
- Analyze content distribution
- Explore ratings and release years
- Create an interactive Power BI dashboard

## 📁 Dataset

The dataset contains information about Netflix movies and TV shows, including:

- Title
- Type
- Release Year
- Age Certification
- Runtime
- Genres
- Production Countries
- IMDb Score
- IMDb Votes
- TMDB Score
- TMDB Popularity

## 📈 Dashboard

The Power BI dashboard provides visual insights into Netflix content and trends.
